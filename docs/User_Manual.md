### 1.2 启动前检查清单 (Checklist)
- [ ] **电源检查**：主机、从机、屏幕、相机、交换机、机械臂控制柜均已上电。

- [ ] **机械臂**：急停按钮已旋开，处于待机状态。

## 2. 💻 主机环境搭建 (Windows)
**注：当前小新主机已装好所需环境，项目位于 `D:\Project\CarPaintDetection`，以下步骤用于在其他设备搭建环境时参考。**
### 2.1 基础环境及依赖
本项目在 Windows 主机端强烈推荐使用 `uv` 进行环境管理，以实现秒级依赖安装。

**第一步：安装 uv 工具**

在 PowerShell 中运行以下命令安装 uv：
```powershell
powershell -c "irm [https://astral.sh/uv/install.ps1](https://astral.sh/uv/install.ps1) | iex"
```
安装完成后，关闭并重新打开终端，输入 `uv --version` 确认安装成功。

**第二步：项目部署与依赖安装**

获取代码：将项目代码 Clone 或下载至本地。

一键配置：进入项目根目录 (CarPaintDetection/)，直接运行 `uv sync`，该命令会自动创建虚拟环境并安装所有锁定版本的依赖，无需手动激活环境。



### 2.2 网络配置 (⚠️ 关键步骤)
为了保证 Socket 通信稳定，主机必须配置静态 IP。

1.  打开 **控制面板** -> **网络和共享中心** -> **更改适配器设置**。
2.  找到连接从机的网口（通常显示为“未识别的网络”），右键 -> **属性**。
3.  双击 **Internet 协议版本 4 (TCP/IPv4)**。
4.  配置如下：
    * **IP 地址**: `10.18.18.10`
    * **子网掩码**: `255.255.255.0`
    * **默认网关**: (留空)
5.  **关闭防火墙**：请关闭专用/公用网络的防火墙，或手动放行 TCP端口 **4096** 和 **4097**。

## 3. ⚡ 从机环境搭建 (Jetson Orin)
**注：当前Jetson Orin从机已装好所需环境，项目位于 `/home/nvidia/Project/CarPaintDetection`，以下步骤用于在其他设备搭建环境时参考。**

### 3.1 基础环境及依赖
1. Jetson Orin不建议采用 `uv` 管理依赖，确保 Jetson Orin 已刷入 Jetpack 系统，配合conda进行环境的安装。

2.  **Basler Pylon Viewer** ：[官方下载链接](https://www.baslerweb.cn/zh-cn/downloads/software/?downloadCategory.values.label.data=pylon)
    * *用于安装相机驱动及测试相机是否正常。*


### 3.2 网络配置与巨帧设置 
从机不仅需要静态 IP(10.18.18.11)，还必须开启 **MTU 9000 (巨帧)** 以支持高吞吐量的图像传输。此功能已在start_client.sh脚本中实现。

**从机一键启动脚本**
项目根目录下提供了启动脚本 `start_client.sh`，它会自动执行以下命令（需要 sudo 密码，密码为 `nvidia`）：
```bash
sudo ifconfig eth0 down
sudo ifconfig eth0 mtu 9000
sudo ifconfig eth0 up
```

## 5. 🚀 系统启动标准流程 (SOP)

**第一步：启动从机 (Client)**
在 Jetson Orin 终端中执行：
```bash
cd CarPaintDetection
./start_client.sh
```

- 成功标志：终端打印 等待主机连接 Port 4096... 且无报错。
- 注意：启动时可能需要输入 sudo 密码以设置 MTU。

**第二步：启动主机 (Server)**
在终端或命令行中执行：
```bash
cd CarPaintDetection
./start_sever.bat
```

- 成功标志：启动 GUI 界面。
- 联机状态：观察 GUI 日志区，应显示 [Control] 已连接！ 以及 [Receiver] 连接来自: 10.18.18.11。

**第三步：开始检测**
确认机械臂处于安全位置。
在主机界面点击 "启动自动检测" 按钮。（可脱离机械臂测试，详细原理见[系统架构设计](/docs/系System_Architecture.md)）
系统将自动执行：机械臂移动 -> 投影条纹 -> 相机采集 -> 算法处理 -> 数据回传 -> 缺陷显示。

## 6. 🖥️ 软件界面说明

软件分为 **离线数据分析 (Offline)** 和 **在线实时监控 (Online)** 两大核心模块，通过顶部的 Tab 页签进行切换。

### 6.1 📚 离线数据分析 (Offline Tab)
用于回溯查看历史检测结果，支持交互式查看缺陷详情。

> ![离线模式截图](/assets/ui_offline.png)

* **左侧导航栏 (Positions)**
    * 显示所有已保存的检测点位文件夹。
    * **操作**：点击列表项，即可切换查看不同点位的数据。
* **中间图像区 (Main View)**
    * **视图切换**：顶部下拉框可选择查看 **相位图 (Phase Map)**、**拼接图 (Stitched)** 或 **原始图 (Raw)**。
    * **交互操作**：支持鼠标滚轮缩放、拖拽移动。
    * **缺陷标注**：图像上直接绘制红色缺陷框，鼠标点击框体可选中该缺陷。
* **右侧详情区 (Details)**
    * **统计面板 (Statistics)**：显示当前点位各类缺陷的数量统计。
    * **缺陷列表 (Defect List)**：列出所有检出缺陷的 ID、类型及置信度。点击某一行，图像区会自动高亮对应缺陷。
    * **特写视图 (Inspection)**：右下角区域，显示当前选中缺陷的局部放大特写图 (ROI)。

---

### 6.2 🚀 在线实时监控 (Online Tab)
用于工业现场的实时作业监控，包含设备控制与实时反馈。

> ![在线模式截图](/assets/ui_online.png)

* **左侧控制区 (Controls)**
    * **启动自动检测**：一键控制全自动检测流程（机械臂运动 -> 投影 -> 采集）。
* **中间监控区 (Monitor)**
    * 实时显示最新回传的检测图像。
    * 同样支持通过下拉框切换观察视角（如查看实时相位解算结果）。
* **右侧看板区 (Dashboard)**
    * **点位信息**：顶部大字显示当前正在检测的 **Position ID**。
    * **实时统计**：表格形式展示当前点位的缺陷计数。
    * **系统日志 (System Log)**：
        * 黑色终端窗口，实时滚动显示系统内部状态。
        * 关键信息包括：TCP 连接状态 (`Connected/Disconnected`)、收到主机指令 (`capture_order`)、异常报错信息等。

## 7. 🔧 常见故障排查 (Troubleshooting)

| 问题描述 | 可能原因 | 解决方法 |
| :--- | :--- | :--- |
| **启动报错 `RuntimeException: Not all cameras...`** | 1. Pylon Viewer 未关闭<br>2. 网线松动 | 1. **务必关闭 Pylon Viewer**，它会独占相机。<br>2. 重新插拔网线，确认相机灯亮。 |
| **主机一直显示 "等待从机连接..."** | 1. 从机未启动脚本<br>2. IP 配置错误<br>3. 防火墙拦截 | 1. 确认从机 `client.py` 正在运行。<br>2. 检查主机 IP 是否为 `.10`。<br>3. 关闭主机防火墙。 |
| **图像传输中途卡死 / 报错 `ConnectionReset`** | **MTU 设置不匹配** | 这是最常见问题。请在从机终端输入 `ifconfig` 确认 MTU 是否为 9000。如果不是，重新运行 `start_client.sh`。 |
| **投影仪没有显示条纹，只有黑屏** | 窗口未全屏或位置错误 | 1. 确保 Windows 显示设置中为 **"扩展模式"**。<br>2. 鼠标点击一下投影画面按 `F11` 或检查 `host.py` 分辨率设置。 |
