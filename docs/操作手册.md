### 1.2 启动前检查清单 (Checklist)
- [ ] **电源检查**：主机、从机、屏幕、相机、交换机、机械臂控制柜均已上电。
- [ ] **LCD屏幕**：主机以 HDMI 线和 DP 线分别连接投影屏幕和用于UI界面展示的屏幕。
- [ ] **相机**：两台 Basler 相机指示灯为绿色（或闪烁）。
- [ ] **网络**：网线连接稳固，交换机已供电。
- [ ] **机械臂**：急停按钮已旋开，处于待机状态。

## 2. 💻 主机环境搭建 (Windows)

### 2.1 基础软件依赖
在使用代码前，请确保安装以下工具：
1.  **Basler Pylon Viewer** ：[官方下载链接](https://www.baslerweb.cn/zh-cn/downloads/software/?downloadCategory.values.label.data=pylon)
    * *用于安装相机驱动及测试相机是否正常。*
2.  **UV (Python包管理器)**：用于快速配置 Python 环境。
    ```powershell
    # Windows 安装命令
    powershell -c "irm [https://astral.sh/uv/install.ps1](https://astral.sh/uv/install.ps1) | iex"
    ```

### 2.2 网络配置 (⚠️ 关键步骤)
为了保证 Socket 通信稳定，主机必须配置静态 IP。

1.  打开 **控制面板** -> **网络和共享中心** -> **更改适配器设置**。
2.  找到连接从机的网口（通常显示为“未识别的网络”），右键 -> **属性**。
3.  双击 **Internet 协议版本 4 (TCP/IPv4)**。
4.  配置如下：
    * **IP 地址**: `10.18.18.10`
    * **子网掩码**: `255.255.255.0`
    * **默认网关**: (留空)
5.  **关闭防火墙**：请关闭专用/公用网络的防火墙，或手动放行 TCP端口 **4096** 和 **4097**。

## 3. ⚡ 从机环境搭建 (Jetson Orin)

### 3.1 基础环境
确保 Jetson Orin 已刷入 Jetpack 系统，并安装了 Pylon for Linux。

### 3.2 网络配置与巨帧设置 (⚠️ 核心坑点)
从机不仅需要静态 IP(10.18.18.11)，还必须开启 **MTU 9000 (巨帧)** 以支持高吞吐量的图像传输。此功能已在start_client.sh脚本中实现。

**从机一键启动脚本**
项目根目录下提供了启动脚本 `start_client.sh`，它会自动执行以下命令（需要 sudo 密码）：
```bash
sudo ifconfig eth0 down
sudo ifconfig eth0 mtu 9000
sudo ifconfig eth0 up
```

## 5. 🚀 系统启动标准流程 (SOP)

第一步：启动从机 (Client)
在 Jetson Orin 终端中执行：
bash```
cd CarPaintDetection
./start_client.sh
```
- 成功标志：终端打印 等待主机连接 Port 4096... 且无报错。
- 注意：启动时可能需要输入 sudo 密码以设置 MTU。

第二步：启动主机 (Server)
在终端或命令行中执行：
bash```
cd CarPaintDetection
./start_sever.bat
```
- 成功标志：启动 GUI 界面。
- 联机状态：观察 GUI 日志区，应显示 [Control] 已连接！ 以及 [Receiver] 连接来自: 10.18.18.11。

第三步：开始检测
确认机械臂处于安全位置。

在主机界面点击 "启动自动检测" 按钮。（可脱离机械臂测试，详细原理见[系统架构文档](/docs/系统架构.md)）

系统将自动执行：机械臂移动 -> 投影条纹 -> 相机采集 -> 数据回传 -> 缺陷显示。
